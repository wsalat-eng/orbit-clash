# Orbit Clash

Браузерная онлайн-игра для двух игроков. Проект не требует сборки, базы данных или платного сервера.

## Локальная проверка

Откройте `index.html` через локальный сервер. Например, в папке проекта выполните:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000` в двух вкладках. Для реальной игры на разных устройствах нужен HTTPS-адрес.

## Бесплатная публикация через GitHub Pages

1. Создайте бесплатный аккаунт на GitHub.
2. Создайте новый публичный репозиторий.
3. Загрузите `index.html`, `style.css`, `game.js` и `README.md`.
4. Откройте `Settings` → `Pages`.
5. В разделе `Build and deployment` выберите `Deploy from a branch`, ветку `main` и папку `/ (root)`.
6. Нажмите `Save` и дождитесь публикации.

После этого откройте ссылку GitHub Pages, нажмите «Создать комнату» и отправьте товарищу код. Второй игрок открывает ту же ссылку и вводит код комнаты.

## Управление

Игрок 1: `WASD` и `Space`.

Игрок 2: стрелки и `Enter`.

## Соло-режим

В меню нажмите «Играть одному». В этом режиме нужно пережить волны дронов:

- уничтоженный дрон приносит 100 очков;
- после каждой полной волны появляется больше и более быстрых врагов;
- красные снаряды дронов наносят урон игроку;
- после окончания игры можно сразу начать новую попытку.
